## ANA KLAUDYA · corpus internacional 2027

La documentación canónica y de festivales se conserva en [`ana-klaudya/`](./ana-klaudya/):

- texto español canónico;
- traducción literaria inglesa;
- dossier internacional;
- subtítulos para corte Cadence 05:58;
- subtítulos para corte Midwest 06:48;
- notas de conformado y versión Weimar.

El texto español y su traducción inglesa quedan actualizados a la **edición canónica cerrada el 09/10/2026**, con siete piezas y **128 versos**. Las adaptaciones internacionales afectan a subtítulos, montaje, silencios y transiciones, no a la voz mediante aceleración mecánica.
